Terry-CN 汉化补丁维护说明

交付给玩家的文件是根目录 Terry-CN-WH3-v0.1.0.zip，正式版本标签为 v0.1.0。
ZIP 只包含差分清单、安装/恢复/检查工具、使用/验证/玩家发布说明和校验文件，共九项，不包含官方完整 DLL。

本工程源码与本地生成目录的用途如下；本地基线、构建和缓存清理后按需重建：
backups/original-20261009：构建所需的官方原版基线，按 README.md 准备并用 source-hashes.json 校验；不入库、不对外打包。
build：候选构建、调用点清单和隔离测试目录，可由原版基线重建；不入库。
reports：保留当前交付的验证报告；回收清单和本机记录仅留在本地。
tests/fixtures：旧补丁升级与快捷键保护的回归测试基线。
tools：构建器、检查器和打包器；tools/python-libs 是按 requirements.txt 安装的本地依赖，不入库。

词库分工：
translations.zh-CN.json：原有汉化词库。
translations.ui.zh-CN.json：已审计的 Terry 界面文字与文件筛选器。
translations.messages.zh-CN.json：可用于共享工具组件的提示和错误消息。
translations.display.zh-CN.json、translations.properties.zh-CN.json：显示层词库。
translations.extended.zh-CN.json：设置、工具、动态 AI 分类和长说明的显示译文。
translations.engine.zh-CN.json：引擎环境和共享界面译文，以及原版中实际存在的大小写变体。
translations.templates.zh-CN.json：UTF-16 模板、UTF-8 拼接片段和诊断消息。
audited-ui-literals.json：静态 Qt 字符串原文、数据地址和引用白名单。
audited-ui-fragments.json：经确认只用于界面的 UTF-8 片段引用及长度操作数。
status-tooltips.zh-CN.json：15 条工具操作说明。
protected-identifiers.json：禁止作为通用字面量改写的配置与快捷键标识。

构建与检查顺序（Python 3，Windows x64）：
先准备原版基线、Python 依赖及下文的旧版升级回归输入。
python tools/build_patch.py --source backups/original-20261009 --output build/new-candidate
python tools/test_display_hooks.py --qt-core "你的 Assembly Kit/binaries/Qt5Core.dll"
python tools/test_static_templates.py build/new-candidate --qt-core "你的 Assembly Kit/binaries/Qt5Core.dll"
python tools/test_font_patch.py build/new-candidate --qt-bin "你的 Assembly Kit/binaries"
python tools/validate_patch.py build/new-candidate
将验证过的 build/new-candidate/patch.json 复制到根目录 patch.json。
关闭 Terry 和 BOB 后运行 python tools/test_installer.py。
实际完成界面、编辑和跨语言保存测试，更新验证说明和报告。
python tools/package_release.py

原生测试记录词库哈希；模板、字体、完整性和安装测试记录差分哈希。场景回读及字体实机报告也须绑定当前差分，
打包器拒绝过期报告。当前分支只保留 v0.1.0 ZIP 及其校验文件。
v0.1.0 将已验证的 R6 更名为正式版，不改变任何目标的差分内容和安装工具。
打包器仅在还原版本字段后重现 R6 清单的完整 SHA-256、安装工具也与原版次一致时，
允许沿用 R6 的原始验证报告；原报告哈希不改写，沿用关系记入 package-verification.json。
只要差分或安装工具发生变化，此更名规则即失效，必须重新提供与当前清单绑定的验证结果。

旧版升级回归输入（仅测试时需要）：
R3、R4、R5 ZIP 及校验文件仍可从 Git 历史取回。在项目根目录执行以下 PowerShell 命令：
$regressionSource = '5a9da4bdb1092fcecb01efbd31596a8264589e5f'
foreach ($regressionVersion in 'R3', 'R4', 'R5') {
    git restore --source=$regressionSource --worktree -- "Terry-CN-WH3-20261010-$regressionVersion.zip" "Terry-CN-WH3-20261010-$regressionVersion.zip.sha256"
}
按各 .sha256 文件核对对应 ZIP 后再运行安装测试；不能因旧包不在当前目录而跳过升级检查。
历史候选 ZIP 及其校验文件已加入 .gitignore，临时取回不会重新加入当前交付。测试结束按项目清理约定移入回收站。
tests/fixtures/patch-r2.json 是必要的回归测试夹具，继续保留。清理当前分支不重写 Git 历史。

源字符串审计不能只检查一种 QString 构造模式。可用以下命令扫描共享文字来源：
python tools/audit_strings.py "你的 Assembly Kit/binaries" build/audit.json --data-strings --module warscape.modder.x64.dll
审计会列出 ASCII 与 UTF-16 候选，也包含内部标识和日志，不能把未匹配数量当作漏译率，
更不能据此全局改写二进制。引擎环境译文通过既有 Qt 显示层生效，不修改 Warscape DLL。

打包器拒绝覆盖同名 ZIP；应先将上次交付移入回收站或保留到明确的归档位置。
构建器继承根目录 manifest 中的已知补丁哈希，旧版升级仍必须使用校验通过的原版备份。

不要将属性键、枚举值、文件路径、资源键或快捷键 ID 翻译后写回模型。
新增词条优先使用显示层；只在确认调用点仅服务界面时改写字面量。
渲染层字典按完整字符串匹配，未知内容透传；编辑框不改写用户输入。
对列表的显示转换不会改变选择项的内部值，但恰好与词条同名的自定义列表名称
也可能显示为译文，编辑和存储的实际名称仍然保留。不要把显示文字当作资源键复制。

当前仅支持 source-hashes.json 对应的 Assembly Kit build 25616861。
官方更新后必须重新审计调用点和 Qt ABI，不能仅修改版本号或跳过哈希校验。

R5 将 toolutilityqt.modder.x64.dll 纳入五目标白名单，只重定向九条文件/Perforce 诊断文字，
不改变命令、状态标记或文件操作。新增基线也由 source-hashes.json 严格校验。
Qt 元对象 tr 的返回遵循成员函数 ABI：rcx 为 this，rdx 为隐藏返回对象，r8 为原文。
它与静态 QCoreApplication::translate 的 rcx 返回对象约定不同；原生测试分别覆盖。

tools/font_patch.py 只调整 Terry 主窗口菜单、工具栏及文字图标的显示。
菜单使用 Microsoft YaHei UI 10 pt，文字图标 9 pt、120×32 画布；独立的 Snap AI 画布同步加宽。
菜单初始化包装保留 MainWindow this、原返回值、Windows x64 栈对齐和影子空间，
附带 UNWIND_INFO，并复制原 PE 异常目录后追加函数记录。必须同时校验原运行时记录完整保留。
不要通过系统 DPI、全局 QApplication 字体或用户 settings.xml 来实现此次字体调整。
字体测试执行重定位后的真实代码并调用原版 Qt；实机检查需覆盖菜单、长标签、
普通与最大化窗口、工具栏溢出入口、快捷键以及中文保存/英文回读。
